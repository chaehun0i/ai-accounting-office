# 고정자산 감가상각 계산 규칙

이 PR은 고정자산 Domain의 **순수 Decimal 계산 규칙**만 추가한다. 취득원가·잔존가치·내용연수·계정 역할을 검증하고 월말 기준 정액법 누적 감가상각을 계산한다. 취득월 전액 또는 익월 시작, 첫 달 일할 계산과 잔존가치 한도를 지원한다. 계산은 Journal/GL이나 DB를 변경하지 않는다.

집중 단위 테스트 3건, Ruff, mypy를 통과했다. DB migration과 API는 없다. 이전 초안의 미완성 API·Repository 코드는 이 PR diff에서 제거했다.

이것은 자산대장 완성이 아니다. 정책 버전의 영속화, POSTED 취득 전표 연결, 감가상각 제안 전표와 독립 승인, 처분·손상·GL 대사, 재고·원가회계는 후속 구현과 PostgreSQL 검증이 필요하다.
